# Валера Android MVP

Первый Android-каркас голосового помощника.

Уже есть:
- foreground service;
- микрофонные разрешения;
- media-вывод в активную Bluetooth-аудиосистему;
- анимированная сфера состояний;
- заготовки под wake-word, Realtime и ERP-команды.

GitHub Actions собирает debug APK из этой ветки.
